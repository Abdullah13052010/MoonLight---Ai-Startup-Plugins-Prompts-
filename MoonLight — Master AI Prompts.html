Beginner-Friendly Guides
From blank box to great output
Three steps that work on every model. No jargon, no theory dumps.

    

      
1
Write a clear prompt
State role + task + format. “Act as a travel editor. Write a 3-day Lisbon itinerary as a table.” Specific beats clever.

      
2
Add context
Give audience, tone, constraints and one example of what good looks like. The model can’t read your mind, only your message.

      
3
Enable plugins & tools
Turn on web search, file upload or code execution in your model’s settings, then tell it when to use them: “Search first, cite sources.”

Personality Prompts
